# Transport — практична робота №5

Реєстраційна система клієнтів для оформлення замовлень на транспортні послуги з підтвердженням через email.

## Швидкий запуск

Потрібен запущений Docker Desktop із Docker Compose. Відкрийте термінал у цій папці:

```sh
docker compose up -d --build
```

- Програма: http://127.0.0.1:8086
- Локальна поштова скринька Mailpit: http://127.0.0.1:8026
